# 3D 粒子互动 · Particle 3D Lab

一个单文件 3D 粒子互动网页：粒子聚成爱心、球体、土星、星系、立方、花朵等造型，可以用鼠标、触摸和摄像头手势控制。

在线演示：https://yangxun0225-netizen.github.io/particle-3d-lab/

## 功能

- 6 种粒子造型：爱心、球体、土星、星系、立方、花朵
- 6 种配色：青蓝、粉紫、暖金、翡翠、彩虹、冰白
- 可调扩散程度、粒子大小、旋转速度、粒子数量（6,000 / 12,000 / 20,000）
- 自动旋转、鼠标推开、重置视角、爆发扩散、全屏
- 摄像头手势（可选，需 https）：手左右移动，造型绕中心竖轴连续旋转，可转满 360 度；攥拳抓取时整个图案收紧缩小到约 0.55×，放开手掌放大到约 1.40×，跟手掌张合 1:1
- 手机端：单指拖动旋转、双指捏合缩放，底部控制台可关闭，默认收起
- 粒子常驻动效：呼吸、摆动、流动、闪烁，每一秒都有变化

## 使用

直接用浏览器打开 `index.html` 即可本地预览；摄像头手势需要通过 `https://` 或 `http://localhost` 打开，浏览器会请求摄像头权限。

也可以直接部署到 GitHub Pages、Cloudflare Pages、Vercel 等静态托管：把 `index.html` 上传到仓库根目录即可。

## 技术

- Three.js（本地 `assets/three.min.js` 已内联进单文件）
- MediaPipe Hands（摄像头手势识别，按需加载；加载失败时自动降级为画面帧差动作感应）
